# Signals beneath the surface

Five original paintings generated with gpt-image-2 in CLI mode. Full prompts are in `generation-prompts.jsonl`.

The full-size WebP files are lossless, with canonical Mnemonic Alphabet color inlays baked into the pixels. Preview files are smaller, lossy images for display only. The gallery decoder samples the full-size files; it does not return hard-coded plaintext. Reading order is left to right; wider gaps separate words. This is a visual substitution cipher, not secure encryption.

Messages verified by reverse-mapping the exported image pixels:

- **Before the first word:** MEMORY BECOMES COLOR
- **The shape of a secret:** SECRETS TRAVEL IN COLOR
- **The ocean remembers:** TAKE ME BACK TO THE SEA
- **A language without words:** ART IS A SECRET LANGUAGE
- **Somewhere, a shore:** FIND YOUR WAY HOME
